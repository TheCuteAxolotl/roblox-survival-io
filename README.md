# Roblox Survival IO

Original Roblox survival/PvP game inspired by fast browser .io loops: gather, build, fight, upgrade.

## v0.1
- top-down angled camera
- gather wood, stone, and food
- melee combat
- place walls and spikes
- XP / age progression foundation
- server-authoritative resources, damage, and building
- Robux monetization hooks using game passes and developer products

## Setup
1. Install Rokit and Rojo.
2. Run `rokit install`.
3. Run `rojo plugin install`.
4. Run `rojo serve`.
5. Open a Roblox Studio Baseplate and connect the Rojo plugin.

Monetization IDs are placeholders (`0`) until the Roblox experience and products are created.
